# HEALTH 1.8 文件批量导入验收

日期：2026-10-01。范围：患者池文件导入、患者中心批量建档。需求、HTML 原型、接口与解析设计、实现均锚定 1.8；页面索引、API 映射、工作区指引已同步。使用现有来源字段与唯一索引，无 SQL 迁移。

## 实现核对

- 共用 Excel/CSV 读取和预览：5 MiB、500 条上限，必填及字段格式逐行校验，错误使用实际文件行号，存在错误禁止确认。CSV 支持 UTF-8、GB18030、带 BOM UTF-16 与引号换行；Excel 支持日期、文本前导零和富文本，拒绝公式/错误单元格。
- 两种空白 Excel 模板有独立说明页；说明中的虚构示例不会进入数据页。ExcelJS 按需加载，CSV 读取不下载该包。
- 患者池沿用原导入接口和来源编号去重，保留人工及粘贴入口；入池后仍由工作人员判定。
- 患者中心新独立 Controller/DTO，整批验证和事务建档，复用现有医生、负责人、机构验证及首次联系任务；来源编号/证件号重复跳过，同批重试幂等。医生和平台管理员不可导入，运营/护士仅分配自己。
- 导入失败保留预览与批次；确认期间锁定输入、关闭和重复提交，重选文件或关闭释放预览。遮罩点击不会丢失待确认数据。
- 批次审计状态固定为 IMPORTED，完整批次在 detail，避免最长 60 字批次超过 after_state 的 32 字上限。日志不输出患者字段或原文件。
