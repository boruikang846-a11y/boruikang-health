- `mvn -B verify`（本地 H2）：管理端 65 项、介绍页 3 项通过，17 项 MySQL 专用用例按既有约定跳过。新增与改写的用例覆盖：只有责任医生能审核随访意见（运营主管、运营人员 403，其他医生 404，通过必填正文、退回必填原因，审核人和时间由会话写入并留审计）；医生只读自己负责的患者、不能建任务 / 录记录 / 改档案；护士只看分配给自己的患者，能起草并提交审核但不能审核；医生确认报告已阅并写意见，已阅后只能更新意见，团队在记录里看到意见；审核随访意见即把关联报告记为已阅；医生审核发布宣教，经理和运营不能发布；升级的临床异常只能由责任医生记录去向后关闭，失联异常由团队核实后直接关闭；随访结果只能由责任医生查收；HTTP 层医生 / 护士登录与菜单范围、主管开通 / 停用 / 重置医护账号立即生效、改密需原密码并换发登录、前端深链接可直接打开。
