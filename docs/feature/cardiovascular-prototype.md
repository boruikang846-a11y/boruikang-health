# 心血管全周期服务探索原型

依据用户2026-10-09方向：保留报告→个案计划→责任医生审核→任务执行→患者反馈→医生查收→复诊核验链路，向患者持续连接和长期专病管理深化。

本次页面范围：统一患者视图、角色待办、长期管理方案浏览、自报指标、计划版本与审批、分阶段反馈闭环、预约人工核验、明确口径的运营漏斗。首期虚构患者以房颤演示；具体试点病种和医学规则由医院确认。

患者专病不能因浏览方案改变；修订医学计划后旧审核失效；临床反馈仅责任医生处理；反馈处理结果保存后等待患者回执核验；患者自报不能标为医院事实；到院核验必须保留来源依据；授权撤回后暂停执行与填报。

交付层次：需求与HTML探索原型先行。现有2.0/2.1设计契约、React/Java/SQL不变。正式实现需在试点确认后另行设计契约与数据模型，沿用Java＋React，现阶段不拆微服务。
