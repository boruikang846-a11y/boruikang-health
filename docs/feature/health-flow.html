HEALTH-MVP-1.2 · 院前到院后的连续服务

出院报告等病历提供个体随访依据，运营团队制定 SOP 并培训医生，医生负责医疗判断，运营人员跟踪执行。

1. 建立关系

基层 / 体检 / 门诊 / 出院 → 医院接口导入（当前 Mock）/ 人工补充建档 → 绑定医生与运营人员

2. 形成任务

人工核对出院报告 / 门诊记录 → 提取原医嘱、注意事项与复诊日期 → 结合运营团队 SOP 准备个体随访内容

3. 审核建议

模板 / AI 草稿 → 医师审核 → 团队人工联系 → 记录实际联系证据

4. 持续跟踪

医护记录人工问询与反馈 → 随访记录 → 异常升级医生 → 处置结果

5. 复诊闭环

协调预约 → 到院证据 → 接诊结果 → 下一次任务

6. 运营复盘

应随访、完成率、异常、到院 → 医生周报 → 团队改进
