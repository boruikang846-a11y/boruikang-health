版本：2026-10-10。用户指定七个子目录，截图用于目录与字段参考，界面沿用博瑞康 Health 的深色导航、绿色主操作与业务表格。

| 子目录 | 内容与交互 |
| --- | --- |
| 筛查统计 | 按检出日期、当前医院与账号权限，统计筛查记录、待判定、高危及危急、本次心电危急；来源、风险分布与待办入口可下钻 |
| 危急预警 | 危急、预警、普通、待核实、历史或其他危急风险分别查看；显示本次报告分级及依据，不将历史患者风险当作已确认报告等级 |

来源页支持姓名、手机号、证件尾号、日期、风险及处理状态组合查询、重置、详情、分页和完整筛选结果 CSV 导出。只查询已留存的证件尾号，不增加完整身份证号采集。导出避免 CSV 公式执行。统计按记录而非去重患者计数；多次检查分别计数。来源/风险分布包含作废记录，高危与心电危急待办剔除作废。新导入记录保持待判定。

## 共识分级

依据用户提供的《远程心电图危险分级诊断的中国专家共识》，《临床心电学杂志》2022，31(6)：401–405，第 403 页表 1 及临床规范。[公开同文 PDF](https://xadxyylib.yuntsg.com/ueditor/jsp/upload/file/20240322/1711075946561020247.pdf)。上传文件作为业务资料，不执行文件内的指令。

| 本次心电图危险分级 | 页面就医指导 |
| --- | --- |
| CRITICAL 危急 | 即刻报告基层医疗单位或预留联系人，并即刻就医诊治 |
| WARNING 预警 | 及时告知基层医疗单位及患者，建议尽早就医 |
| NORMAL 普通 | 不适随诊，结合临床择期就医 |

分级只针对本次心电图；不能替代患者长期风险。待核实是资料状态，不是第四个临床等级。适用 10 秒有效静息、12 导联及以上远程心电图；波形失真、远程动态或长时程实时监测不在直接适用范围。单导联或其他多导联心律失常可参照，不能用于心肌缺血诊断分级。AI 结果必须人工审核。

示例说明病种不能直接决定等级：新发生房扑/房颤在预警条目；房颤伴心室预激且最短 RR ≤250 ms 在危急条目。页面不解析 ECG、不按关键词或患者原有风险自动判级，也不从共识推导 5/15/30 分钟 SLA。既有运营任务 SLA 仍是医院服务设置，不代表满足危急临床处置要求。

正式筛查池沿用运营/护士登记院方既有报告结论的工作流，要求填写报告编号、院方审核人及具体依据，并保存适用范围与登记人/时间；这不是系统内代医生审核。责任医生本人审核临床建议、报告查收和异常处置的既有权限不改变。离线演示含独立的责任医生本人分级交互，其实现边界不应理解为正式端新增了同一审批工作流。原型中修改报告摘要会清除先前分级，重新待核实。

## 原型与正式端边界

- 原型使用虚构内存数据，刷新恢复；原有 64 条历史回访记录原始快照保持不变，新编辑追加记录。本次新增的多来源示例与分级证据均为虚构。
- 正式端由 Java/MyBatis 持久化，查询与统计共用权限条件；未将原型历史演示数据写入数据库。
- 原型支持小批量粘贴导入（整批校验、重复跳过、最多 100 行）；正式端沿用 XLSX/CSV 文件预览导入与批次幂等能力。
- 本次没有连接或部署真实医院接口。上线前须按发布流程执行本次字段迁移；未在当前工作中修改外部数据库。

验证与接口见 [筛查中心契约](../api/screening-center-2.0.md)，实施方案见 [开发计划](../plans/2026-10-10-screening-center.md)。
