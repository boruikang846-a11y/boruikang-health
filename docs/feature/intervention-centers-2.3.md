# 诊后主动干预中心 2.3

本轮依据 2026-10-10 用户明确要求开发。侧栏“诊后主动干预”改为“诊后主动干预中心”，下设门诊、住院、体检、咨询、转诊五个服务中心，各自按院前、院中、院后提供实际工作队列。既有个案计划、随访、预约、转诊和患者档案保留。

## 可办理内容

| 中心 | 院前 | 院中 | 院后 |
| --- | --- | --- | --- |
| 门诊 | 导诊咨询、预约准备、就诊资料核对 | 到院核验、检查指引、报告领取协助 | 门诊随访、复诊跟踪、用药反馈收集 |
| 住院 | 入院协调、资料准备、床位衔接 | 住院服务、出院交接、护理需求协办 | 出院随访、康复反馈、复查准备 |
| 体检 | 体检预约、检前准备、套餐咨询 | 检查协调、漏项跟进、报告进度 | 报告解读、异常复查、检后回访 |
| 咨询 | 就医咨询、报告咨询、挂号协助 | 院内咨询、投诉协办、检查咨询 | 随访咨询、评价回访、复诊咨询 |
| 转诊 | 转诊申请、接收协调、资料核对 | 到院核验、诊疗反馈、接诊协作 | 回转交接、转诊随访、后续安排核验 |

上述为新建入口与服务事项建议。实际工作单支持自定义标题、服务事项、内容、截止时间、阶段、中心、关联报告和修改原因；既有工作单固定患者，责任团队随患者档案分派。跨中心转接保留工作单编号与完整历史。没有新增收费、实际号源预约、床位调配或自动执行临床指令。

## 岗位操作

运营主管查看本院工作单；运营人员和护士只处理分派给自己的患者；医生只处理自己负责的患者。平台管理员不能查看患者工作单。

普通服务：新建 → 开始处理或修改 → 登记结果 → 核验闭环。临床服务：关联原报告 → 提交 → 当前责任医生本人确认原报告已阅并审核 → 运营/护士登记结果 → 当前责任医生本人查收 → 核验闭环。医生可以退回并写明原因，团队修改后重新提交。

每次修改都清除原审批、查收状态，回到处理中；不能把临床单降级为普通单。责任医生改派后，旧医生失去权限，旧审批不能执行。已闭环、已登记结果的工作单需重新打开后修改，历史记录保留。执行临床服务前再次校验患者服务授权。

所有办理动作必须填依据；人工实际到院需要过去或当前的时间和凭据；评价仅在登记结果后填写 1–5 分与真实反馈，每单一次。各动作保存版本，过期提交返回冲突并要求重新读取，不覆盖他人修改。

## 咨询服务中心

从第一张参考图提取响应队列、超时跟进、咨询协作、实际到院与评价投诉等有价值内容。正式管理端提供待受理、待审核、超时、到院、满意评价及未闭环投诉统计，以及可搜索的工作单和完整协作历史。离线演示另展示当前阶段最近六条协作动态与首次处理均值，属于演示看板。

统计按当前医院、患者权限、中心、阶段、患者及标题搜索范围计算，单位为工作单；状态/超时筛选只过滤列表，不缩减同范围统计卡。满意为 4–5 分，有凭据才计入到院；不把工作单完成计为实际就诊。无渠道扫码/会话消息数据时，不编造扫码人数、触达率、消息量或转化收入。
