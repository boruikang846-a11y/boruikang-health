## 已发现的冲突与决定

1. 参考资料部分按收入比例激励医生，用户明确表示比例提成不可行：本期不做分成结算。
2. 参考 PRD 有 AI 直接问询/自动回复构想，用户要求“AI 给意见，人负责回答”：所有建议必须医师审核，由团队人工联系并在后台记录证据。
3. 心血管文档聚焦房颤/PCI/心衰，会议要求所有科室：基础模型保留科室与通用 SOP，心血管作为示例。
4. 部分资料给出临床风险阈值，但没有试点医院批准依据：不默认上线自动诊断/风险引擎，由医师手工分层和处置。
5. 已有运营 SOP，未找到可认定为本试点医院签字生效的完整临床 SOP：模板仅用于采集与提醒，正式医院 SOP 待交付并审核。
