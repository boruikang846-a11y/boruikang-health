团队交接

  1. 完成后，责任医生查看记录并确认接收。
  2. 反馈异常单独升级，不能仅在文本中写“已处理”。
  3. 次日查看应复诊名单，用医院事件或核验证据确认到院。
  4. 护士保存日归档，团队完成周复盘。
  5. 周报打印后，记录人工外发凭证；不冒充系统自动发送。
