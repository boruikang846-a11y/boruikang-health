接续实现约束

分页、失败重试、提交忙碌态贯穿各页面。管理端分派变更使全部关联任务 version 递增并要求新医生重新审核；患者端不展示内部备注。MANUAL 为人工编辑草稿，仍须提交审核。设置页仅平台管理员可改接入凭证，其他医护只查看接入状态。登录后按角色进入工作台或接入设置；侧栏可打开系统介绍。出院随访按关联报告人工制定个体内容，模板仅带入原记录周期和复诊日期。

患者中心文件导入交互（1.8）

患者中心页头“文件导入” → 上传文件（模板、拖拽与选择） → 校验与分配（原文件行号、错误/重复筛选、医生与负责人、可选首次联系任务） → 导入结果（批次、新增与跳过原因） → 本批新增清单 / 患者档案。错误阻止整批导入；重复跳过，不覆盖已有档案。主管可选本院负责人，运营与护士固定本人，医生与平台管理员不可导入。

专项入口与完整原型共用同一页面；实际 Excel/CSV 本地解析，演示确认只更新虚构内存与时间轴，刷新恢复初始状态。
