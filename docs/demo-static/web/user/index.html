谁负责哪一步

我们 · 运营团队

制定、发布服务 SOP，培训医生，组织任务执行与服务复盘。

医生

接受 SOP 培训、按流程协作，负责医学判断与个案建议审核。

健康管家 / 护理团队

核对报告、准备随访、人工联系、记录反馈并升级异常。

随访内容从哪里来

患者的个体依据

出院报告 / 原始就诊记录

人工核对出院诊断、原医嘱、注意事项、用药周期与复诊日期。

团队的统一流程

我们制定的服务 SOP

规定如何联系、问询、记录和升级问题，并用于医生培训。

两类依据共同支持个体随访内容 → 责任医生审核 → 团队人工联系

一次随访怎样完成

01

核对报告

报告与患者、任务关联。

02

准备随访

结合原报告和服务 SOP。

03

医生审核

核对个案建议，人工联系。

04

跟踪结果

记录反馈、异常与复诊证据。

数据以医院接口为主；本期使用虚构 Mock 导入并支持人工补充；报告上传、OCR、自动解析与患者业务入口均未开放。
