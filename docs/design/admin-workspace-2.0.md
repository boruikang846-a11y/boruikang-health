# HEALTH 2.0 正式工作台与原型对齐

当前参考为 `docs/demo-static/web/index.html` 的 2.0 原型；正式交付为 React 工作台，不把离线演示页面部署为业务系统。

共享框架：66px 全宽顶栏 `#1d2632`，220px 侧栏 `#26303f`，绿色选中项与主操作 `#299e60`，内容背景 `#f1f5f5`，白色卡片、5px 圆角、浅边框。顶栏包含品牌、角色、姓名、修改密码和退出；菜单沿用代码生成的角色契约。窄屏侧栏收起，表格内部横向滚动。移除原有蓝色渐变主按钮、半透明面板和装饰动画。

患者中心顺序为分类、统计、文件导入、筛选和清单；医生保留相同分类与统计，隐藏写入入口。统计覆盖当前账号全部可见患者，分类在服务端筛选并分页。患者档案默认展示报告，支持 `?tab=journeys` 进入本患者旅程，保留其他已实现台账与审计功能。

全旅程清单展示两条服务路径，阶段说明直接读取生成的 2.0 契约；详情依次展示本次事件与阶段责任表、医疗依据与计划、任务、咨询异常投诉、追加历史。暂停、退出和结案分别标注，不用水平步骤条压缩长阶段名称。所有操作继续调用正式 API，沿用授权、版本、本人办理、依据和审计要求。

系统介绍、登录、工作台、患者及旅程、任务、渠道、配置等页面采用同一套颜色和组件边框。原型中的虚构记录与开发数据库的演示记录数量可以不同，页面不得硬编码原型人数或把外部集成显示为已接通。

本轮复用现有 patient 字段，数据库无结构变更或迁移。查询与统计接口由 HTTP 集成测试检查医院、医生、护士与运营权限范围及分页；原型行为由现有四层契约检查验证。发布必须先通过 PR 合入 develop，再由 boruikang-workflows 的 dev-health-deploy 发布 admin。
