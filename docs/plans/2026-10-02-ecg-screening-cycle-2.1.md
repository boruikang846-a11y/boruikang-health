# 心电一张网 + 心血管疾病全周期管理：诊前筛查原型 2.1

依据用户提供的流程图，新增诊前工作链路。图片作为产品流程参考，不作为经验证的临床规则。

## 页面结构

诊前筛查中心包含：筛查与分层、心电一张网接入、干预与绿色通道、全周期复盘。入口覆盖体检、慢病、门诊、社区；每个对象保存来源机构、来源编号、原心电报告、异常提示、责任医生及执行负责人。

优先复核异常提示独立突出。AI 提示、医生确认分层、业务执行阶段分别展示，风险颜色同时附带文字，避免仅靠颜色表达。

## 状态与角色

- 待复核 → 责任医生本人确认红 / 黄 / 蓝分层。
- 红色：医生登记高危处置与承接 → 团队核实实际到诊 → 医生确认管理需求与入组。承接通知不等于到诊，不能用普通预约代替高危处置。
- 黄色：团队核实身份、联系 → 绿色通道预约 → 核实到诊 → 医生确认入组。
- 蓝色：保留筛查档案与复查安排；需要进一步评估时沿用预约和到诊流程，不自动宣告无需管理。
- 未接通或身份未核实：记录原因与下次联系时间，不能直接预约。
- 入组只由责任医生本人确认；生成患者档案、保留原心电来源和报告、生成首次待执行随访。联系和到诊记录迁移至既有台账，诊前审计关联患者档案。

护士与运营仅看分配对象；医生仅看负责对象；主管看全部；平台管理员无患者访问。所有状态变化只存在当前页面内存，刷新或重置清除。
