# 数据接入测试原型

本轮实际读取用户提供的 XLSX，使用与页面相同的本地解析器，识别 64 条明细且校验错误为 0。标题行及汇总区被排除。结果预置至回访邀约台账，并记录首批本地原型导入成功。

脱敏：姓名替换为演示对象，电话替换为 000 开头的不可联系号码，机构人员与沟通正文不留存，医学结论使用虚构提示。性别、年龄、风险、来源、P 状态、到诊标记与日期完整性保留。原 Excel 不变，文件不上传。

运营主管从侧栏“数据接入测试”可选择实际 .xlsx、加载预置文档脱敏样例、测试外部正常响应 Mock 或模拟超时。流程：选择 → 自动识别字段 → 脱敏预览 → 校验 → 确认导入 → 批次结果 → 台账。

支持参考表 23 列表头，必需字段校验，最多 500 条 / 5MB。错误整批阻断。同一文件内重复来源编号阻断。同一来源重复导入跳过，Excel 与外部 Mock 使用不同命名空间。

验证：实际 Excel 64 条、高危 18、危急 4；预置 64 条重放跳过 64 条；外部正常 Mock 新增 1 条，重复确认跳过 1 条；超时不改变台账；运营人员不能执行导入。

结果仅写当前页面演示状态，预置数据随 HTML 提供，新增批次刷新后清除。不写生产后端、患者数据库或真实外部系统。外部接口状态仍为未接通。代码级与实际文件解析检查通过，不代表浏览器点击、布局或真实系统联调验收。
